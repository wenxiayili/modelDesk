# Roadmap / 路线图

中文 | [English](#english)

## 0.1.x - 开源 MVP 稳定化

- 完善 README、许可证、第三方声明和贡献流程。
- 提高 Windows 安装包稳定性。
- 收敛 UI 细节，继续贴近专业模型查看器的信息密度。
- 扩展资源诊断覆盖面，优先处理 glTF、OBJ/MTL、Babylon 资源链。

## 0.2.x - 文件与资源工作流

- 最近项目和最近文件夹。
- 资源缺失修复建议。
- 贴图通道预览。
- 批量显示/隐藏材质和网格。
- 更清晰的资源扫描上限提示。

## 0.3.x - 视图与测量

- 正交/透视切换。
- 前、后、左、右、顶、底视图预设。
- 保存/恢复相机视角。
- 角度测量、尺寸标注和测量导出。

## Later

- 多标签或多窗口。
- 更完整的 FBX 动画支持。
- 插件式导入器。
- 模型健康报告导出。

## English

## 0.1.x - Open-source MVP Stabilization

- Complete README, license, third-party notices, and contribution process.
- Improve Windows installer reliability.
- Refine UI details and keep the information density close to professional model viewers.
- Expand resource diagnostics, prioritizing glTF, OBJ/MTL, and Babylon resource chains.

## 0.2.x - File and Resource Workflow

- Recent projects and recent folders.
- Suggestions for fixing missing resources.
- Texture channel preview.
- Batch show/hide for materials and meshes.
- Clearer resource scan limit warnings.

## 0.3.x - View and Measurement

- Orthographic/perspective switch.
- Front/back/left/right/top/bottom view presets.
- Save and restore camera views.
- Angle measurement, dimension annotation, and measurement export.

## Later

- Tabs or multiple windows.
- More complete FBX animation support.
- Pluggable importers.
- Model health report export.
